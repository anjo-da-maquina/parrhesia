**1/7 — 問題**
> AIコーディングエージェントが一番やる手抜き:テストを直さずに消す。例外を握り潰す。終了コードを0に固定する。そして「全テスト合格」と報告する。
> QAエンジニアとして、これを自動で検出するツールを作った。

**2/7 — デモ**
> やったこと: 「AIが書いたような修正コミット」を仕込みで作り(手抜き5パターン入り)、ツールに監査させた。
> 結果: 5/5件検出、diffだけから、0.1秒以内。

**3/7 — 仕組み**
> 検出パターン: テスト関数の削除・新規skipマーカー・assertの正味減少・新規except:pass・終了コードのハードコード。
> git log/git show の出力だけを読む。コードは一切実行しない(読み取り専用)。

**4/7 — 許可不要であることの証明**
> アカウント不要・APIキー不要。さらに、ネットワークインターフェース自体が存在しない名前空間(Dockerの--network noneより厳格)の中でデモを再実行し、それでも完走・5/5検出することを確認した。

**5/7 — 正直な失敗**
> このデモの最初の実機実行は、5件中2件しか検出できなかった。サンプルコードが検出器の正規表現と一致していなかったため。その失敗と修正は、今もコミット履歴にそのまま残っている。隠していない。

**6/7 — 限界**
> パターンベースであり、意味理解はしない。コードが「正しいか」は判定しない。「全部検証済み」という文章の真偽も判定しない(別の仕組みが必要で、それは未接続のまま正直に書いている)。
